# Project screenshot folders

Add authentic, publishable screenshots to the matching folder. Use numbered descriptive filenames such as `01-dashboard.png`, `02-details.png`, and `03-workflow.gif`; then add each file and an accurate alt description to `CurrentImages` in `Pages/Home.razor`. Images are served from `wwwroot`, so paths in that list begin with `images/projects/`. The case-study dialog automatically shows carousel controls when a project has more than one listed image.

Folders: `agro/`, `settra/`, `inventopro-picknpack/`, `hris/`, `master-data/`, `request-monitoring/`, `gasta/`, and `capstone/`.

Only add images that are safe to make public. Remove or obscure names, customer data, credentials, internal records, and other confidential information before adding screenshots. PNG, JPEG, WebP, and GIF files are supported by browsers. Prefer optimized PNG/WebP for screenshots; use GIF only when motion conveys useful product behavior.
